# Project Emberfall — Bastion System

Last Updated: 2026-07-04

---

Every player owns a personal Bastion. The Bastion represents the player's home and grows alongside the character. Players begin with almost nothing.

## Progression Tiers

1. Ember (Campfire)
2. Campsite
3. Wilderness Camp
4. Cabin
5. Outpost
6. Fort
7. Keep
8. Citadel

## The Bastion Provides

- Resting
- Skill progression
- Crafting
- Storage
- Trophy displays
- Guild facilities
- Future customization

The Bastion should become a visual representation of the player's journey.
