# Project Emberfall — Project Vision

Author: Adam Boeckmann
Last Updated: 2026-07-04

---

## Vision

A mobile-first fantasy RPG inspired by the feeling of old-school MUDs and classic RPG progression while embracing modern accessibility.

Players create a single persistent character that grows through actions, choices, training, and exploration.

The goal is to create a world where players become emotionally invested in their character over months or years.

## Core Philosophy

- This is not a hero collection game.
- This is not pay-to-win.
- Players should win because they make better decisions, not because they tap faster or spend more money.
- Progression should come from use and practice, not from waiting on a level-up timer.

## Design Pillars

- One persistent character
- Train what you use
- Meaningful progression
- Deliberate tactical combat
- Exploration and discovery
- Player identity over character collection

- A game built around tactical, readable combat

## What Emberfall is NOT

- A hero-collection gacha game
- A pay-to-win game
- A fast-reflex action combat game
